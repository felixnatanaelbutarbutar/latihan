🚀 Panduan Lengkap: Cara Fork & Kirim PR

  1. 1

    Fork Repository

    Buka halaman repository ini di GitHub, lalu klik tombol Fork di kanan atas untuk membuat salinan di akun GitHub kamu.

  2. 2

    Clone ke Komputer Lokal

    Buka terminal/Git Bash di komputer, lalu ketik perintah berikut (ganti dengan username kamu):

    git clone https://github.com/USERNAME_KAMU/latihan.git
cd latihan
  3. 3

    Buat Branch Baru

    Biasakan membuat branch baru sebelum mengedit kode:

    git checkout -b tambah-profil-namamu
  4. 4

    Edit File contributors.js

    Buka file contributors.js di VS Code atau text editor pilihanmu, lalu tambahkan profil kamu pada array kontributor.

  5. 5

    Commit dan Push

    Simpan perubahan, lalu jalankan perintah commit dan push:

    git add contributors.js
git commit -m "feat: tambah profil namamu"
git push origin tambah-profil-namamu
  6. 6

    Buat Pull Request (PR)

    Buka repository asal di GitHub. Akan muncul tombol hijau Compare & pull request. Klik tombol tersebut, beri judul, lalu kirimkan PR-mu!
